# v0.9 Plan (temporary, 26 November 2026)

v0.9 finishes v0.8's live checks, adds the last touches to Galaxy One, makes Galaxy One the
first Unranked galaxy with Fame, tells the operator about end votes, has the bots answer
treaties, closes the one confirmed leak from the original list, and takes a slice of
accessibility. It is not the mobile client, which is a release of its own.

not here, so this file holds no checkboxes and a search for open items counts the sources

file when v0.9 ships.

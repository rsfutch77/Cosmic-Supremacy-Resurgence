For cosmicresurgence.com: the static archive of the original Cosmic Supremacy site, the override pages written for the revival, and the launcher download. Rerun the items a change touches before each `firebase deploy --only hosting`.

Written for the published site. Unchecked items are the gap to it. Scope is what the live site serves; archive content not yet migrated and published (the forum, unstaged pages) is outside it until it is (R6).

**Sources.** W3C Web Content Accessibility Guidelines 2.2 (W3C Recommendation, 12 December 2024; criterion text reproduced under the W3C Document License, https://www.w3.org/TR/WCAG22/) and the Opquast Digital Quality Framework, Rules 2025, version 5.0 (CC BY-SA 4.0, https://checklists.opquast.com/en/digital-quality/; rule text reproduced, and this checklist is shared under the same licence). The R items paraphrase guidance documents and cite each. Target: WCAG 2.2 Level AA. See `Checklist_Sources.md` for why these sources were chosen.

Generated by `build_website_checklist.py` beside this file.

- [ ] **R3** The site's response headers pass the Observatory tests: Content-Security-Policy, Strict-Transport-Security, X-Content-Type-Options, frame-ancestors, Referrer-Policy, and the rest.

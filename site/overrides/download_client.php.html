Playing Cosmic Supremacy without the Installer

This is the original Cosmic Supremacy client, patched to talk to a server that runs on your own machine, packaged with a launcher that starts it. There is no installer: unzip the archive wherever you like and run CosmicSupremacyLauncher.exe from the folder you unzipped it to.

File Name:CosmicSupremacy-Resurgence-v0.1.0.zip
Download Size:30.1 MB
Date Published:13.09.2026
SHA-256:83ece812f1601a5b417b789aecf8752b92d270a843c400872d2b83ada16f6f97

Windows will most likely warn you about an unrecognised publisher, because the build is not code-signed. The SHA-256 above lets you check that the file you downloaded is the one that was published.

To uninstall, delete the folder. Nothing is written outside it and nothing is registered with Windows.

System Requirements

Supported Operating Systems: Windows 10 / 11

Minimum Required Hardware: 1.5 GHz CPU, 512 MB memory, 200 MB free hard-disk space, DirectX 9 compliant graphics-card with at least 128 MB of graphics-memory.

Required Libraries: None to install. The client uses DirectX 9 and GdiPlus, and Windows 10 and 11 both ship with them, so neither redistributable is needed any more.
